# Water & Break Reminder

A C# Windows Forms desktop application designed to help users maintain healthy habits by reminding them to drink water and take regular breaks.

## Features

- Customizable water reminders.
- Customizable break reminders.
- Independent reminder timers.
- Desktop notifications.
- Audio alerts.
- System tray support.
- User-configurable settings.

## Technologies

- C#
- Windows Forms
- .NET
- Visual Studio Community
- Git & GitHub

## Team

Three developers working collaboratively on UI/UX, timer logic, and notifications.
